# Зерно — сайт кофейни

Next.js 16 + TypeScript + Tailwind CSS 4. Сделан по документу `coffee_shop_claude_design_system.md`.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000

Чтобы сразу посмотреть кабинет с бонусами и заказами: «Войти» → «Посмотреть демо-аккаунт».

## Где что лежит

| Папка | Что внутри |
|---|---|
| `src/data` | Меню, ингредиенты, цены, кофейни, правила лояльности — **менять меню здесь** |
| `src/services` | Работа с данными (сейчас mock на localStorage, потом заменить на API) |
| `src/hooks` | Корзина, авторизация, уведомления, конструктор напитка |
| `src/utils` | Расчёт цены, бонусов, форматирование |
| `src/components` | Интерфейс по разделам |
| `src/app` | Страницы |

Как добавить напиток: добавить объект в `src/data/products.ts`.
Как добавить сироп или молоко: добавить объект в `src/data/ingredients.ts`.
Настоящее фото товара: указать поле `image: "/images/latte.jpg"` и положить файл в `public/images`.
